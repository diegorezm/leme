# Extra themes

Themes that are not built into Leme. To use one, copy the `.toml` file into
your themes folder (`%APPDATA%\leme\themes\` on Windows, `~/.config/leme/themes/`
on Linux) and run **Reload config and themes** from the palette.

| Theme | Kind | From |
| --- | --- | --- |
| `caderno.toml` | dark | Caderno design system, night sheet (`paper`, `ink`, `lamp`) |
| `caderno-linho.toml` | light | Caderno design system, linen sheet (`log-paper`, `log-ink`, `terra`) |
